# Source provenance

## Historical restartable sources before 2026-10-22

The physical transport, wall, collision, random-number, sampling-kernel,
precision, and reconstruction implementation originates from the validated JFM
production solvers in commit `0904a6dc2f7b6aabfe1bcd6aefe3d19640fe4265`.

Original SHA-256 values:

- HS: `d234a93910403bcf4429ab2b20767a2a7d35349b27dab3016d257abfa5881f6f`
- BGK/Shakhov: `c20d1a5fac0ab7e019e695a68e7ddecc64571f63102a8a957f61d766d6b4db55`

The restartable version adds only statistical snapshot and continuation I/O plus
loop offsets required to resume from a completed step. It does not change the
advance, boundary, collision, random-number, sorting, or sampling kernels.

Restart state contains:

- all particle positions and velocity components;
- per-particle RNG state;
- HS cell RNG, NTC majorant and collision counters, or relaxation-model
  diagnostic counters;
- float64 moment accumulators and per-block sampling counts;
- the completed step, physical parameters and cumulative wall time.

Arrays are written individually as uncompressed `.npy` files to avoid a
multi-gigabyte host-memory spike. `manifest.json` is written last and the
temporary directory is atomically renamed, so the loader accepts only a
complete restart. Equal-width time blocks are enforced across segments.

Restartable SHA-256 values:

- `solver/JFM_hs_dsmc_quarter.py`:
  `2c9e2f5119802b123f0335664a564085cfe77682ae4f4af4138dc31f5876b166`
- `solver/JFM_bgk_shakhov_quarter.py`:
  `f2f97526942c53eca0af6dd9b94aca541f06951db4755a92cc8fb11e5e0e65a2`

## Corrected sources published on 2026-10-22

The current `solver/JFM_bgk_shakhov_quarter.py` changes the Shakhov heat-flux
polynomial from `c2/(2*theta)-2.5` to `c2/theta-5`, restoring the intended
Pr=2/3 with the physical half-prefactor definition of q. Its version is
`2026-10-22-jfm-bgk-shakhov-restartable-v3-pr23` and its SHA-256 is:

- `e05ffd201443333143ceb3ce6b86c34eb30d228863fe42cacdfd1f878b32fcd1`

HS and BGK collision formulas are unchanged. The corrected Shakhov loader
requires a `shakhov_heat_flux_polynomial` manifest marker equal to
`c2/theta-5`. Historical Shakhov restarts lack this marker and are rejected
before their arrays are loaded. This prevents silently mixing two collision
models or retaining their accumulated samples. Existing results remain
historical and have not been regenerated by this correction.

The missing shared module and validation drivers were recovered from Unity:
`/project/pi_roohie_umass_edu/JFM_revision_2026/JFM_CORRECTED_V3`.
The shared `JFM_reviewer_quarter_domain.py` SHA-256 is
`ade0824c20779d325a57da6d76ec9976fd0d52ca7493ca1dd34276002a6f87bc`.
This byte-identical module already contains the full-strength Shakhov
correction and is a different source lineage from restartable-v2.
The restored three-seed conductivity summaries reproduce the manuscript's
rounded HS conductivity and paired model ratios. This supports their Fourier
validation provenance; it does not establish that historical cavity fields
were computed with the corrected kernel.

`provenance/unity_recovery_20261022.json` records each recovered source path,
size, original SHA-256 and bundled SHA-256. Driver import paths were relocated
for this repository layout; the shared module and data were copied byte for
byte. Only task-related source code and compact validation records were
retrieved. No cluster source, active job or particle checkpoint was modified.

Verification for this repair consists of independent Gaussian mass, momentum,
energy and heat-flux moment tests of both actual weight expressions, recovered
source/dependency/statistic checks, restart round trips, rejection of the old
Shakhov collision model, and the existing CPU preflight checks. No fresh GPU
simulation was performed or claimed.
