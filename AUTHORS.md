## Software provenance

The files in this package were recovered from Ehsan Roohi's UMass Unity PI
project space and cross-checked against the public research branches of
`Ehsan-Roohi/DSMC_Python`. Exact source hashes and the validated predecessor
commit are recorded in `SOURCE_PROVENANCE.md`.

Article authorship, code authorship, and copyright ownership are related but
not automatically identical. This file preserves the known scientific
attribution without asserting exclusive ownership for any contributor.
